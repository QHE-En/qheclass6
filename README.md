# qheclass6

从零学 Java 后端，SpringBoot + MyBatis-Plus 项目。

## 技术栈

- Java 21
- Spring Boot 4.0.8
- MyBatis-Plus 3.5.14
- MySQL 8
- Maven

## 功能

- 查所有用户：GET /users
- 新增用户：POST /users
- 修改用户：PUT /users
- 删除用户：DELETE /users/{id}

## 项目结构

## 怎么运行

1. 本地装好 MySQL，建数据库 `qhe`，建表 `user`
2. 改 `application.properties` 里的数据库密码
3. 运行 `Qheclass6Application`
4. 浏览器访问 `http://localhost:8080/users`
